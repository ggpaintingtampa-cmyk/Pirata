Pirata app schematic

Morgan el Pirata is a private team operations app for a small painting / service business.

Bottom tabs:
- Work: daily progress, active timer, current goals, important tasks, and Projects.
- Ask: natural-language assistant for business records through server-approved operations.
- Updates: shared project activity, human-written messages, recent changes, and file/photo context.
- Menu: grouped access to Projects, Calendar, Progress, Today, Inventory, Clients, Shopping, Files, Team accounts, Settings, and owner-only administration.

Core flow:
Sign In -> Work -> Projects -> Project Detail -> Tasks, Updates, Notes, Files, Client.
Work -> Tasks -> Task Detail -> Subtasks, Timer, Schedule, Files, Notes.
Work -> Calendar -> Progress.
Menu exposes the full app.

Security:
Private to authorized team members. Server enforces permissions for APIs, snapshots, downloads, live updates, and AI tools. Uploaded files are stored outside the public web root and require authenticated downloads.

Design:
Preserve the dark Pirata theme, fast task capture, small floating Add button, Work landing screen, prominent Projects access, and bottom navigation. Keep it operational, polished, and phone-friendly for a painting crew.

Prompt for Figma AI:
Use this schematic and the screenshots in this file as context. Propose improvements that make the app faster for a painting crew on phones while preserving the current dark theme, private team workflow, fast task capture, and bottom navigation: Work, Ask, Updates, Menu.
